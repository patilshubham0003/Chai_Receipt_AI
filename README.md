# ChaiReceiptAI

ChaiReceiptAI is an AI-powered chai receipt generator built using Python and Streamlit. It allows users to enter customer details, select chai items, calculate the total bill, generate a personalized quote using a Generative AI LLM, and download the generated receipt.

## Features

* Enter customer name
* Select chai items
* Add quantity
* Calculate total bill
* Generate personalized AI quotes
* Display the quote on the receipt
* Download the receipt

## Technologies Used

* Python
* Streamlit
* Generative AI

## How to Run

Install the required libraries:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
